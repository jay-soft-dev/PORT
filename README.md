# Rohit Anil Shinde — Mechanical Engineering Portfolio

A responsive, blueprint-inspired personal portfolio website built to showcase the academic background, industrial training, engineering projects, and technical toolkit of **Rohit Anil Shinde** (B.E. Mechanical Engineering.

## Key Features

- **Engineering Blueprint Aesthetic:** Dark CAD-grid background (`style.css`) with amber/stone industrial color accents and responsive Tailwind CSS layout.
- **Interactive Academic Journey Tabs:** Dynamically switches between **B.E. (Current)**, **Diploma (MSBTE)**, and **SSC (10th)** milestones using vanilla JavaScript (`script.js`).
- **Projects & Industrial Training Section:** Highlights the **Hydraulic Press Machine** project and a **3-month industrial internship** at Mapson India Pvt Ltd (Bhosari, Pune).
- **Technical & Digital Skills Matrix:** Showcases core competencies including **AutoCAD & CATIA**, **EV Maintenance & Measuring Tools**, **Mechanical Engineering**, and **Advance Excel / MS Office / MSCIT**.
- **One-Click Contact Copy & Toast Alerts:** Instant clipboard copy for email and phone number with live toast feedback.
